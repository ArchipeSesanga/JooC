# Product Backlog - JooC

## Weekly Planning
- Create a new Board (week)
- Add a Column for each day of the week
- Add a Card to a day (meal or item)
- Edit a Card's text
- Delete a Card
- Mark a day as "no meal planned"

## Shopping List
- View all items marked "needed" across the week
- Mark an item as bought
- Add a standalone shopping item (not tied to a meal)

## Reminders
- Local notification on shopping day
- Notification if today's meal has no ingredients logged

## Carry-Over & History
- Unbought items roll into next week automatically
- View a past week (read only)
