# Epics — JooC

- **Weekly Planning** — create a week (Board), add days (Columns), and fill in meals/items (Cards) for each day.
- **Shopping List** — flat list of household items needed for the week, markable as bought.
- **Reminders** — notify me on shopping day and if a planned meal for today has no ingredients logged.
- **Carry-Over & History** — unbought items or unplanned days roll into the next week; past weeks are viewable.
- **Auth** — basic single-user login (or none, if this stays local-only for now).
